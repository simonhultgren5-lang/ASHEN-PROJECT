# Ashen Eclipse

A browser-based dark fantasy action RPG with three classes, linked skill gems, procedural dungeons, and endgame encounters.

## Run locally

Requires a Node.js version supported by Vite 8.

```sh
npm ci
npm run dev
```

Open the local URL printed by Vite. The game saves progress in your browser.

## Checks

```sh
npm run lint
npm run build
```
